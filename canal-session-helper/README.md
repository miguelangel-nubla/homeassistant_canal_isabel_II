# Ayudante de sesión del Canal de Isabel II

Un navegador que se ejecuta en tu servidor para la integración [Canal de Isabel II](https://github.com/miguelangel-nubla/homeassistant_canal_isabel_II) de Home Assistant. Inicias sesión en la oficina virtual a través de él, y él entrega la sesión a la integración, la mantiene y te avisa cuando hay que volver a entrar.

Sustituye a copiar la cookie a mano. No inicia sesión por ti ni guarda tus credenciales.

Se puede usar como complemento de Home Assistant o como contenedor Docker. Las instrucciones de ambos están en [DOCS.md](DOCS.md).
